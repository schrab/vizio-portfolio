# Контекст проекта: Портфолио художника Степана (vizio-portfolio)

## 1. Описание проекта и бизнес-задача
**Цель:** Создать минималистичный, конверсионный одностраничный сайт-визитку (лендинг) для профессионального художника (Степана). 
**Целевая аудитория:** B2B сегмент (владельцы кофеен, ресторанов, отелей, крупный бизнес), которым нужна уникальная роспись фасадов, интерьеров или создание эксклюзивных объемных деревянных панно.
**Особенность:** Фокус на визуальном контенте (разноформатные фото и видео процессов). Текст универсальный, без привязки к конкретным странам. Реализован адаптивный дизайн (Responsive UI) с поддержкой свайп-каруселей на мобильных устройствах.

## 2. Технический стек
*   **Генератор статики:** Jekyll (GitHub Pages).
*   **Хостинг:** GitHub Pages (репозиторий: `schrab/vizio-portfolio`).
*   **Фронтенд:** Чистый HTML5 / CSS3 (Grid / Flexbox), без тяжелых CSS-фреймворков.
*   **Типографика:** Google Fonts (Playfair Display для заголовков, Manrope для текста).
*   **Темы оформления:** Встроенная поддержка Dark Mode (по умолчанию) и Light Mode с сохранением выбора в `localStorage`.
*   **Многоязычность:** Реализуется через подпапки (`/` для RU, `/en/` для EN, `/vi/` для VI). Контакты динамически адаптированы под каждую языковую версию.

## 3. Архитектура проекта
```text
/vizio-portfolio
├── _config.yaml         # Глобальные настройки
├── _layouts/
│   └── default.html     # Основной шаблон (Header с переключателями, Main, Footer)
├── assets/
│   ├── css/
│   │   └── style.css    # Стили сайта, медиа-запросы, CSS-переменные для тем
│   ├── images/          # Оптимизированные фото портфолио
│   └── videos/          # Видео (дроны, процессы создания)
├── index.md             # Русская версия сайта (готово, контакт Telegram)
├── en/
│   └── index.md         # Английская версия (готово, контакт WhatsApp)
└── vi/
    └── index.md         # Вьетнамская версия (готово, контакт Zalo)
```
