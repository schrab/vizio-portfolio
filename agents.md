# Контекст проекта: Портфолио художника Степана (vizio-portfolio)

## 1. Описание проекта и бизнес-задача
**Цель:** Создать минималистичный, конверсионный одностраничный сайт-визитку (лендинг) для профессионального художника (Степана). 
**Целевая аудитория:** B2B сегмент (владельцы кофеен, ресторанов, отелей, крупный бизнес), которым нужна уникальная роспись фасадов, интерьеров или создание эксклюзивных объемных деревянных панно.
**Особенность:** Фокус на визуальном контенте (разноформатные фото и видео процессов). Текст должен быть универсальным, без привязки к конкретным странам (упоминания локаций удалены).

## 2. Технический стек
*   **Генератор статики:** Jekyll (GitHub Pages).
*   **Хостинг:** GitHub Pages (репозиторий: `schrab/vizio-portfolio`).
*   **Фронтенд:** Чистый HTML5 / CSS3 (без тяжелых фреймворков типа Bootstrap/Tailwind, чтобы сохранить легкость и полный контроль).
*   **Многоязычность:** Реализуется через подпапки (`/` для RU, `/en/` для EN, `/vi/` для VI).

## 3. Архитектура проекта
```text
/vizio-portfolio
├── _config.yaml         # Глобальные настройки (baseurl: "/vizio-portfolio")
├── _layouts/

│   ├── css/
